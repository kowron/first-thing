## Plan
### 1. Czym jest apoptoza (D 165–166)
- (a) Wyjaśnić przebieg zmian morfologicznych jako ciąg (rycina 1) i rozpoznać komórkę we wczesnej / późnej apoptozie.
- (b) Problem (usuwać komórki bez szkody dla sąsiadów i bez zapalenia) → definicja, energia i geny, C. elegans (B10) → nazwy (PCD, dawne/obecne znaczenie) → pojedyncze komórki, godziny → stan wyjściowy błony (fosfatydyloseryna, asymetria) → zmiany po kolei: woda/obkurczenie, jądro (chromatyna, otoczka – definicje), pęcherzyki, ciałka (błona zachowana), fagocytoza (makrofag) → zapowiedź: kto to robi (kaspazy tną, Bcl-2 pilnuje mitochondrium).
- (c) chromatyna – rozdz. 9 (krótko).
- (d) Przykład: dwie komórki w preparacie – która jest dalej w apoptozie.
### 2. Kaspazy (D 167–169)
- (a) Wyjaśnić, czym jest kaspaza, dlaczego powstaje jako prokaspaza, jak się aktywuje (inicjatorowe vs wykonawcze) i co tnie.
- (b) potrzeba (pociąć białka) → białko, wiązanie peptydowe, proteaza, cysteinowa, za Asp → 14 kaspaz, ICE/ced-3 (B10) → zymogen, prodomena (DD: DED/CARD), p20, p10 (masy – C19) → aktywacja: cięcie za Asp, 2×p20 + 2×p10 → inicjatorowe (CARD/DED = uchwyt do białka adaptorowego, autoproteoliza) vs wykonawcze (tnie je inicjatorowa) → kaskada → substraty (laminy – otoczka jądrowa; cytoszkielet; ICAD/CAD; PARP; DNA-PK; Rb, MDM2) i skutek.
- NOWA rycina: prokaspaza → aktywna kaspaza (wg ryc. 8.4 D).
### 3. Rodzina Bcl-2 (D 166–167, 171)
- (a) Wyjaśnić mechanizm „bramy mitochondrialnej”: kto ją otwiera (Bax po tBid), kto trzyma zamkniętą (Bcl-2), co z tego wynika dla losu komórki.
- (b) stan wyjściowy: cytochrom c w przestrzeni międzybłonowej (dwie błony), poza nią → Apaf-1 → kaspaza 9 → wykonawcze → nazwa, onkogen t(14;18) (rozdz. 9), Ced-9 (B10), 26 genów, splicing (Bcl-XL/Bcl-XS) → dwie grupy – pełne listy (B6) → domeny BH, TM → gdzie leżą → co robi każda grupa (stabilizacja, ROS, cyt c; Bax–VDAC–pory; Ca²⁺, kaspazy) → przewaga grup (bez „stosunku Bax/Bcl-2”), p53 → Bax/Bcl-2 (C20, rozdz. 2).
### 4. Szlak zewnętrzny i wewnętrzny (D 168–171)
- (a) Zestawić dwa szlaki wg kryterium: skąd sygnał i która kaspaza inicjatorowa go odbiera; prześledzić każdy krok (sprawca → czynność → skutek); pokazać połączenie (Bid).
- (b) tabela-kryterium → receptor/ligand (def.) → Fas: DD–DD, DED–DED, DISC (zasada „domena z domeną tego samego typu”) → TNFR1, TNFR2 (B7) → DAXX, JNK (kinaza – def.), Rac-1 (C18) → wewnętrzny: wyzwalacze (ROS – def.) → megakanał pełny (B8) → skutki w mitochondrium → uwalniane białka → apoptosom (Apaf-1 = adaptor jak FADD; CARD–CARD) → kaspaza 9 → wykonawcze → Bid (100×).
- (d) Przykład: komórka z nieczynnym apoptosomem – które sygnały nadal mogą ją zabić.
### 5. Trzy szlaki dodatkowe (D 172–174)
- (a) Dla każdego: czym różni się od dwóch głównych (źródło sygnału, enzym inicjujący, związek z mitochondrium).
- (b) pseudoreceptorowy (CTL, NK, perforyna, granzym B jako „zastępca kaspazy inicjatorowej”, granzym A – bez kaspaz) → ceramidowy (wtórny przekaźnik – def., pełny mechanizm B2: fosfocholina, cholesterol, obojętna/kwaśna, sfingozyna, S1P) → stresowy (ER, kaspaza 12) → tabela porównawcza.
### 6. Fizjologia (J 126)
- (a) Wyjaśnić na czterech przykładach, które komórki organizm usuwa i co się dzieje, gdy apoptoza zawiedzie.
- (b) zasada: komórki nadmiarowe / niefunkcjonalne / niebezpieczne → zarodek (syndaktylia) → grasica (antygen, selekcja negatywna) → uszkodzone komórki → uszkodzone DNA: p53 (rozdz. 2) → G1/S → Bax → cyt c (powrót do Bcl-2) → radioterapia.
### 7. Zaburzenia (J 126–127, D 174)
- (a) Od zasady „za dużo / za mało” do chorób; wyjaśnić, dlaczego blokada apoptozy sprzyja nowotworowi i oporności na leki; przypisać każde zaburzenie miejscu w szlaku.
- (b) zasada → tab. 11.4 pełna (B3) → nowotwory: p53, mutacje, oporność → cztery zaburzenia ↔ miejsce w szlaku → leki (B4) z logiką działania → neurodegeneracja: Alzheimer (Aβ, tau, stres ER), Parkinson.
- (d) Przykład: chłoniak z nadmiarem Bcl-2 i lek uszkadzający DNA – krok po kroku.
### 8. Znaczniki starzenia (A 138–144)
- (a) Rozpoznać starzenie: przy każdym znaczniku – co to, dlaczego świadczy o starzeniu, jak wykryć; zrozumieć, dlaczego trzeba kilku.
- (b) problem (hodowla przestała rosnąć – czy to starzenie?) → definicja, replikacyjne/przyspieszone → grupy, uniwersalne/swoiste → morfologia, SA-β-Gal (C16, GM1), ziarnistość, lipofuscyna, cytoszkielet (C17) → przypomnienie cyklu (rozdz. 2; B12) → proliferacja (BrdU/EdU, Ki67) → inhibitory (B13) → zatrzymanie (B9) → DNA-SCARS → SAHF (B11) → PML → telomery (C14; rozdz. 6/9 – FISH, Southern) → lamina B1 (C15) → 8-oksyGua → metylacja → SASP (C23) → onkogeny → zastrzeżenie i wniosek → tabela metod (B5).
- (d) Przykład: hodowla przestała rosnąć – jaki zestaw znaczników odróżni starzenie od przegęszczenia i braku surowicy.
